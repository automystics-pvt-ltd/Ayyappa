# 🛕 வடமதுரை அருள்மிகு ஸ்ரீ ஐயப்பன் திருக்கோவில் – நிர்வாக (Admin) மற்றும் நன்கொடை மேலாண்மை அம்சங்கள்

## 🎯 நோக்கம்

இந்த இணையதளம் **திருப்பணி மற்றும் மகா கும்பாபிஷேக நிதி திரட்டும் (Crowdfunding)** நோக்கத்திற்காக உருவாக்கப்படுகிறது.

பக்தர்கள் **QR Code / UPI** மூலம் நன்கொடை வழங்கலாம். அந்தப் பரிவர்த்தனையை (Transaction) நிர்வாகி (Admin) சரிபார்த்து உறுதி செய்த பிறகே, அவர்களின் பெயர் **"இதுவரை நன்கொடை வழங்கியோர் விவரம்"** பகுதியில் தானாக இடம்பெற வேண்டும்.

---

# 🔐 நிர்வாக உள்நுழைவு (Admin Login)

நிர்வாகி மட்டுமே உள்நுழையக்கூடிய பாதுகாப்பான Admin Panel இருக்க வேண்டும்.

Admin-க்கு மட்டுமே பின்வரும் செயல்பாடுகள் இருக்க வேண்டும்:

* நன்கொடை விவரங்களை சரிபார்த்தல்
* நன்கொடை வழங்கியவர்களின் பெயரை சேர்த்தல் / திருத்தல் / நீக்குதல்
* கோவில் செய்திகள் வெளியிடுதல்
* திருப்பணி முன்னேற்றத்தைப் புதுப்பித்தல்
* புகைப்படங்கள் மற்றும் வீடியோக்களை பதிவேற்றம் செய்தல்
* முகப்பு பக்க உள்ளடக்கங்களை மாற்றுதல்
* QR Code மற்றும் வங்கி விவரங்களை மாற்றுதல்
* அனைத்து இணையதள தகவல்களையும் நிர்வகித்தல்

# 💰 நன்கொடை (Donation Workflow)

## பக்தர் செய்ய வேண்டியது

1. QR Code Scan செய்து பணம் செலுத்துதல்.
2. தனது பெயர்
